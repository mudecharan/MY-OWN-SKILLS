# Executive Communication Rules

## The pyramid principle (Minto)
Answer FIRST, then the 3 arguments, then the evidence. Executives decide early;
structure lets them follow your reasoning instead of waiting for the point.
Topic titles ("Q3 churn analysis") waste a slide; action titles
("EMEA churn doubled — we need a save play this quarter") deliver it.

## One message per slide
If you need "and" in the title, split the slide. The visual carries the message;
the title states it; body text only when unavoidable.

## Numbers for executives
- Business units first ("$1.2M ARR"), statistical framing in appendix.
- Ranges when honest: "+8–12% with current evidence."
- Compare to something they know: "= one enterprise deal per quarter."

## Managing the room
- Pre-wire the decision with key stakeholders BEFORE the meeting; surprises in the
  room kill recommendations regardless of quality.
- Put methodology and messy detail in appendix — visible readiness to be challenged
  builds more trust than explaining unprompted.
- End with THE ASK: decision, owner, deadline, resources, next-week plan.

## Language hygiene
| Instead of | Say |
|---|---|
| might possibly suggest | indicates / shows |
| statistically significant | real effect, here's the size |
| utilize, leverage | use |
