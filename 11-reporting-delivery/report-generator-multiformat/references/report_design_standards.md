# Report Design Standards

## Structure (answer-first, always)
1. **Headline** — the takeaway in one sentence + the headline number.
2. **Bottom line up front** — 3 bullets: what happened, why it matters, recommended action.
3. **Evidence** — tables/charts that carry the argument; each with a message caption.
4. **Method & caveats** — one short section; details to appendix.
5. **Next steps** — owner + date per action.

## Style rules
- Numbers in business units with comparisons ("$1.2M — one enterprise deal/quarter").
- Every chart gets a takeaway title, not a topic title.
- One idea per section; if a section needs "and", split it.
- Ranges over false precision when data is thin.
- Data freshness line under the title ("data through 2024-06-30").

## Format guidance
| Format | Use for | Notes |
|---|---|---|
| Markdown | versioning, wikis, AI consumption | source of truth |
| HTML | email/web sharing, links | styled via house CSS |
| PDF | formal distribution, attachments | print CSS, page breaks before h2 |

## Length budgets
- Executive summary ≤ 1 page / ~400 words.
- Standard report 2–4 pages; appendices unbounded but separated.

## Recurring reports
Keep a content template per report type; only numbers + commentary change week to week.
Track "last sent" and "data-as-of" per issue to catch staleness.
